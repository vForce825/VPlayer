# HomePod 物理音画同步与脱敏证据验证工具 (`PhysicalSyncEvidence`)

本工具是针对 Apple TV 与 HomePod 物理音画同步验收（设计说明书第 13.3 节）的独立 macOS Swift 工具（Swift 6，macOS 14+），独立于 tvOS 播放主工程，不链接至 `VPlayer.app`，用于对采集硬件、脱敏归档记录、36 事件统计以及完整证据信封进行确定性重算与零信任验证。

---

## 1. 工具定位与设计原则

1. **确定性 Canonical CBOR 封闭 Schema**：
   - 严格仅支持 RFC 8949 最短整数编码、负整数（major 1: `-1 - n`）、定长 byte string 与数组。
   - 彻底拒绝 map、tag、float、text string、不定长编码、可选字段与尾随字节。
   - 整数溢出检查：包含加减乘除、交叉相乘排序、纳秒换算与计数的全量 checked 运算。
2. **精确有理数 (`ExactRational`)**：
   - 采用分子 `Int64` / 分母 `UInt64 > 0` 并基于最大公约数（GCD）进行自动约分。
   - 所有时刻、插值、偏移量与 630 个 Theil–Sen 斜率在最终判定门槛前均保留绝对精确有理秒，不使用浮点数舍入。展示值仅在最终格式化时按 nearest-even 舍入至 $1\,\mu\text{s}$。
3. **逐帧 Pre-write 隐私准入与容量限制**：
   - 图像归一化至 $640 \times 360$ 8-bit full-range luma（$230,400$ 字节）。
   - 在任何写入、mask 或摘要计算前进行页面/布局/状态准入，任何未列入 manifest 的状态、通知、弹窗或自由文本一律拒绝并立即清零 scratch 缓存。
   - 仅在允许保留的安全 ROI 区域复制像素，其余区域固定置零。
4. **零信任证据重算**：
   - Validator 绝不采信调用方传入的摘要，必须由底层原始报告、采集文件与连续归档流全链路从头重算环境摘要、UI 证据、Control 证据、Boundary 身份与 Transaction Preimage。

## 2. 运行与验证指南

### 2.1 构建与单元测试

在仓库根目录下，直接使用 Swift Package Manager 执行：

```bash
# 运行完整测试套件（覆盖 CBOR、ExactRational、统计、检测器、校准、隐私准入、归档验证与 Golden 向量）
swift test --package-path Tools/PhysicalSync
```

### 2.2 运行命令行验证工具

本工具具有**冻结命令行参数契约**。为了保证发布运行证据与构建提交的严格一致性，除空参数外，任何附加参数均会被拒绝并返回退出码 `64`。

```bash
# 标准执行（参数必须为空）
swift run --package-path Tools/PhysicalSync physical-sync-evidence
```

若传入任何非空参数（如 `--flag`），工具将报错退出：
```text
错误：命令行参数必须为空（冻结参数契约）。当前传入参数：["--flag"]
```

### 2.3 真实物理硬件缺项报告

根据设计第 13.3 节要求，无法取得同时包含高速画面与物理声压的真实采集证据时，**严禁伪造测量或输出“物理通过”**。

在无真实物理采集硬件接入的环境下执行工具，将明确输出以下中文硬件缺项诊断：

- `[缺失] 240fps+ 物理高速相机与未压缩视频流`
- `[缺失] 48kHz 单声道物理麦克风与 ADC 采集链`
- `[缺失] CaptureSkewCalibratorV1 同步发射硬件`
- `[缺失] HomePod 与 Apple TV 物理测试环境`

**结论**：当前环境缺少真实物理采集硬件，无法生成“物理通过”报告；但已完成纯值算法、CBOR 编码器、统计学断言与合成数据全量自动化校验。

## 3. 统计判定门槛与 36 事件规约

每个物理同步单元严格使用 $36$ 个唯一事件（ID $0\dots35$）：

| 统计指标 | 归约算法 | 合格判定门限 |
|---|---|---|
| **绝对中位数** | 绝对偏差 $\{a_i\}$ 排序后第 18、19 项算术平均 | $\le 40\,\text{ms}$ |
| **Nearest-rank p95** | 绝对偏差 $\{a_i\}$ 排序后第 35 项（$\lceil 0.95 \times 36 \rceil$） | $\le 80\,\text{ms}$ |
| **最大绝对偏差** | 绝对偏差 $\{a_i\}$ 排序后第 36 项 | $\le 100\,\text{ms}$ |
| **有符号中位数** | 有符号偏差 $\{e_i\}$ 排序后第 18、19 项算术平均 | 记录归档，无单独阈值 |
| **Theil–Sen 漂移斜率** | 所有 $i < j$ 共 630 个斜率排序后第 315、316 项算术平均换算为 $\text{ms/min}$ | 绝对值 $\le 1\,\text{ms/min}$ |

任何时间倒序、重复时刻、事件缺失或数值溢出均导致单元判定失败。
